# Quiz 2 - Test Driven Development

This project demonstrates Test Driven Development (TDD)
using Java and JUnit 5.

## Part 1: Calculator
Implements arithmetic operations and even number checking.

## Part 2: DateChecker
Determines whether a month has 31 days.

## Technologies
- Java
- Maven
- JUnit 5

## Development Process
The project follows the Red-Green-Refactor TDD cycle.
Tests are written before their corresponding implementations.
